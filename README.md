# IronPulse Gym Membership + Cypress

## Requirements
- Node.js 22.x recommended
- VS Code
- Chrome

## Install
Open this folder in VS Code terminal:

npm install

## Start app
npm run dev

Open http://localhost:5173

Demo login:
Email: admin@ironpulse.com
Password: admin123

## Run Cypress
Keep the Vite server running in one terminal.

Open Cypress:
npm run cypress:open

Headless:
npm run cypress:run

## Build
npm run build

## Main features
- Login validation
- Dashboard
- Member CRUD
- Member search
- Membership plans
- Payment records
- Attendance
- Reports
- Logout
- LocalStorage persistence
- Responsive maroon / black / white UI
- Cypress E2E tests
